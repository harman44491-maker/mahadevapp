# Mahadev AI Shorts Maker

Android app + Node.js API for YouTube discovery and publishing of videos you own or are licensed to use.

## Current features
- Android dashboard branded **Mahadev AI Shorts Maker**.
- Fetches India's public YouTube most-popular video metadata.
- Google OAuth connection for the user's YouTube channel.
- Encrypted OAuth token storage in PostgreSQL using AES-256-GCM.
- Protected channel-details endpoint.
- Protected YouTube video upload endpoint with title, description and Private / Unlisted / Public visibility.
- Android video picker and upload form.
- FFmpeg processing endpoint: trims a selected clip, reframes it to 9:16, and burns Hindi speech captions generated by Google Cloud Speech-to-Text.
- Free photo-to-video endpoint: creates a 10–60 second 9:16 MP4 with natural, cinematic, or combined camera pan/zoom motion. This is not AI face animation or talking-photo generation; it runs locally on the Render service using FFmpeg and has no paid AI API dependency.
- Facebook Page Reels publishing endpoint using the Meta Page Reels API.
- Scheduled YouTube publishing via YouTube `publishAt`, and scheduled Facebook Reels via `video_state=SCHEDULED`.

## Render environment
Required:
- `YOUTUBE_API_KEY`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI=https://mahadev-ai-shorts-maker-api.onrender.com/auth/youtube/callback`
- `DATABASE_URL` (Neon pooled PostgreSQL URL)
- `TOKEN_ENCRYPTION_KEY` (64 hexadecimal characters; keep stable or previously encrypted tokens cannot be decrypted)
- `APP_API_KEY` (long random secret required by the app for protected endpoints)
- `GOOGLE_SERVICE_ACCOUNT_JSON` (base64-encoded or raw service-account JSON with Cloud Speech-to-Text access; enable the Speech-to-Text API)
- `FACEBOOK_PAGE_ID` (the Page ID)
- `FACEBOOK_PAGE_ACCESS_TOKEN` (Page access token with `pages_show_list`, `pages_read_engagement`, and `pages_manage_posts` permissions)
- Optional `META_GRAPH_VERSION` (defaults to `v27.0`)

Never commit secrets or put them in source code. If a secret is exposed, rotate it.

## Google OAuth
OAuth consent screen must include the account as a test user while the app is in Testing mode. Authorized redirect URI must exactly match:
`https://mahadev-ai-shorts-maker-api.onrender.com/auth/youtube/callback`

## API endpoints
- `GET /` service information
- `GET /health` health check
- `GET /api/youtube/trending?regionCode=IN&maxResults=20` public trending metadata
- `GET /auth/youtube` start Google OAuth
- `GET /auth/youtube/callback` OAuth callback
- `GET /api/status/integrations` integration status
- `GET /api/youtube/channel` requires `x-app-api-key`
- `POST /api/youtube/upload` multipart form fields `video`, `title`, `description`, `privacyStatus`, optional ISO `publishAt`; requires `x-app-api-key`
- `POST /api/photo/video` multipart fields `photo`, `durationSeconds` (10–60), and `style` (`natural`, `cinematic`, or `both`); returns a free 9:16 camera-motion MP4; requires `Authorization: Bearer` user session.
- `POST /api/video/process` multipart fields `video`, `startSeconds`, `durationSeconds` (3–60 seconds); returns a 9:16 MP4 with Hindi captions burned in; requires `x-app-api-key`
- `POST /api/facebook/reels` multipart fields `video`, `title`, `description`, optional ISO `publishAt`; publishes or schedules a Facebook Page Reel; requires `x-app-api-key`

## Build Android APK
Pushes to main run the Android build workflow. The debug APK is uploaded as a GitHub Actions artifact named `mahadev-ai-shorts-maker-debug-apk`.

## Important limitations
- Trending API returns metadata only; it does not provide rights to download or repost videos.
- Hindi captions require Google Cloud Speech-to-Text credentials and may incur Google Cloud charges. Free Render instances have limited CPU/RAM and may sleep; video processing can time out on long/heavy source files.
- Facebook Page publishing requires a valid Page access token, required Page permissions, and any Meta app review/verification that Meta requires. This implementation uses the configured Page token; it does not include an in-app Meta OAuth login flow.
- Scheduled publishing is platform-side scheduling after upload, not an always-running background scheduler. YouTube/Facebook must accept the requested schedule time.
- Google OAuth in Testing mode is restricted to added test users. Public release may require Google's verification depending on scopes.
- Render Free services may sleep and have limited CPU/RAM; large video uploads can time out or exceed memory limits.
- Upload only content you own or have explicit permission to publish.
